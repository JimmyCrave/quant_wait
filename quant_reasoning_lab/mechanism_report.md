# 量化推理变长的机制实验：mechanism_report

模型：DeepSeek-R1-Distill-Qwen-1.5B；量化条件（分析前固定，未更换）：AWQ-W3 g128 数值模拟（权重反量化后以 bf16 存储，**不是真 3-bit kernel**，不讨论速度/显存实测）。
GPTQ3 未使用，因为 AWQ3 已验证可用。题目：与第一阶段相同的 100 道 MATH-500；采样 T=0.6、top-p=0.95。
所有规则、阈值、前缀库/锚点选择规则均在查看对应结果之前写入 `configs/prereg.yaml` 或对应脚本头部。偏离预注册之处在第 8 节逐条列出。

> 证据等级标注：**[观察]** 描述性统计；**[相关]** 观察性比较，有混杂可能；**[反事实]** 同前缀配对续写；**[干预]** 位置受控干预；**[未验证]** 假设。

## 勘误与后续验证（2026-10-11，详见 `dur_study/duration_report.md`）

* **评分器口径（影响数字）**：第一阶段评分器会对未结束（无 `</think>`）的轨迹从思考文本里抽取数值给分。AWQ3 的"准确率"在第 1 节和第一阶段表里被高估：评分器口径 0.405，严格口径（`</think>` 之后有完整且正确的 `\boxed`）**0.255**；λ=1 在种子 42 上的收益严格口径为 +0.26，评分器口径 +0.12。BF16 不受影响。B3/B5 的结局本来就是严格口径，不受影响；B2 里 `accuracy`、`frac_reached_correct_final_score1` 两列用的是评分器分数。
* **第 4 节表格口径**：BF16/AWQ3 两列是按前缀平均，差值列是按题目加权；最大偏差 0.024，结论不变。
* **marker 覆盖**：惩罚只含 49 个带前导空格的 token（` recheck` 被切成两个 token 已排除）；无空格变体（如行首 `Wait`）不被惩罚，在 AWQ3 轨迹里它们的频率反而高于被惩罚的 token。
* **第 6/9 节"短窗口无效"的后续**：在 32 个锚点上延长窗口，32 token 无效，256 token 证据不足（受切换伪影上界限制），1024 token 的收益大（+0.35），但其中约 26 个百分点是 BF16 在窗口内直接写完整个回答；切回后的保留只有描述性证据。人工盲审 60 窗口已导出但**未完成**。

## 0. 一句话结论

三种机制在数据里**同时出现**（入口、出口、提交都变差），结论归为**混合机制**；但"短窗口 BF16 校正"在三个预先指定的位置、窗口 8/32/64 token 下**全部没有可检出的收益**，也不优于等预算随机窗口，所以机制证据不足以支持"局部位置修复"这类在线方案，**按预注册规则 B6 未实现**。
整个续写实验的样本量很小（28–48 个题目簇），区间很宽；循环/L 的定义对结论强度有影响（见第 2 节可靠性）。

## 2. B1 状态标签与可靠性（`state_annotation_protocol.md`、`annotation_pack/`、`results/audit_*.csv`）

* 分段：段落合并到 ≥150 字符（不跨 `</think>`），保留字符与 token 位置映射。合并规则是在看到任何标注结果之前加入的（AWQ3 循环会产生上万个单行段落）。
* 候选检测（只出候选，不作标签）：5-gram Jaccard≥0.6 / zlib 压缩比<0.25（文本重复）；bge-small 余弦≥0.90 且无新符号（语义重复）。未使用 Wait/But/Alternatively 作为特征。
* 自动标注器：Qwen2.5-14B-Instruct（全量，温度 0，隐藏精度配置/种子/答案）；phi-4（全量，作第二标注器）。**没有任何人工标注，没有人工金标准。** 匿名标注包（120 个窗口 × 10 步 = 1200 行，含分层 normal_G / repetition_candidate / valid_correction_candidate / near_end / near_answer，BF16 与 AWQ3 各半）已导出，供人工复核；人工已复核样本数 = 0。
* 答案位置：labeler 的 ANS 字段 + `<think>` 内所有 `\boxed{}`，用第一阶段同一个评分器离线判对错（正确答案不用于任何在线环节）。

可靠性（120 窗口，1200 个思考步）[观察]：

| 比较 | L vs 非L 的 κ |
|---|---|
| Qwen（有检索证据）vs Qwen（无检索证据） | 0.69 |
| Qwen vs phi-4 | 0.42 |
| Qwen 审计运行 vs Qwen 全量运行（仅分块不同） | 0.60 |

* U 的比例：Qwen 1.8%，Qwen 无证据 4.9%，phi-4 0.2%。
* 标注器对 L 的认定差异很大：Qwen 把 65% 的步骤标为 L，phi-4 只有 40%。在**检测器无任何候选**的 normal_G 窗口里，Qwen 仍把 33%（BF16）/ 56%（AWQ3）标为 L；抽查（由本助手读取，**不是独立人工**）发现的主要失败模式：对不同数值重复同一计算模板（如依次代入 x=-7.5、-7.25……）被标成 L，按协议这应是 G。
* **可靠性在 BF16 上明显更差**：Qwen-L ∧ 检测器候选 的"高置信 L"，phi-4 同意率在 AWQ3 为 83%，在 BF16 仅 44%。因此"基于 labeler 的循环"在 BF16 上被高估，比较 BF16/AWQ3 时存在**差异化测量误差**。
* 对策（按预注册"可靠性不足先做高置信度子集"）：报告四种状态定义并列：`auto`（Qwen 全部标签）、`hc`（Qwen L∧候选；Qwen G∧无候选）、`cons`（Qwen 与 phi-4 都同意 ∧ 候选/无候选，其余 X）、`det`（**无标注器**，仅"近似逐字重复"检测器）。`det` 是**事后加入**的敏感性变体（见第 8 节），它定义严格（只抓逐字/近逐字循环），但完全不依赖 LLM。覆盖率：hc 在审计窗口覆盖 62% 的步（L 39%，G 23%），选择偏差：hc 的 L 在 AWQ3 覆盖 53% 而 BF16 只覆盖 25%，G 则相反；即高置信子集更偏向"明显循环的 AWQ3"。

## 3. B2 入口、出口、提交（`state_transition_results.csv`、`figs/survival_{auto,hc,cons,det}.png`）

分母：每个配置 400 条轨迹 / 100 个题目簇；区间为按题目聚类的 bootstrap（B=500）。完整表含每项的事件数与分母（`entry_events`、`entry_atrisk_steps`、`n_spells`、`n_spells_censored` 等）。

### 3.1 入口 G→L [相关]
进入风险 = 每 1000 个"处于 G 的步骤"里开始一次 ≥2 步 L 的次数（以风险步数为分母，不按事件总数比较）。

| 状态定义 | BF16 | AWQ3 | 比值 |
|---|---|---|---|
| auto | 270 | 435 | 1.6× |
| hc | 80 | 192 | 2.4× |
| cons | 24 (17–32) | 100 (82–120) | 4.1× |
| det（逐字重复） | 3.3 (1.7–5.3) | 45.8 (41.3–50.6) | 14× |

四种定义方向一致。轨迹中至少出现一次循环的比例：det 7% vs 74%，cons 40% vs 88%。入口风险随轨迹位置**上升**（AWQ3 det：每 1000 个 G 步 26/80/138，三等分位置），不是平稳过程。

### 3.2 L 的持续与出口 L→G / L→A [相关]
L 段持续时间用 Kaplan–Meier（轨迹在 L 内结束或预算耗尽 = 右删失；出口到"模糊"状态也按删失处理）。

| 状态定义 | S(2000 token) BF16 / AWQ3 | KM 中位持续 token BF16 / AWQ3 | 8000 token 内回到 G 的累计发生率（竞争风险）BF16 / AWQ3 |
|---|---|---|---|
| auto | 0.02 / 0.21 | 328 / 606 | 0.89 / 0.81 |
| hc | 0.21 / 0.62 | 756 / 12527 | 0.63 / 0.35 |
| cons | 0.41 / 0.79 | 1408 / 未达到 | 0.40 / 0.19 |
| det | 0.09 / 0.35 | 239 / 552 | 0.97 / 0.79 |

四种定义下 AWQ3 的 L 持续更久、回到 G 更少。但 hc/cons 因"出口到模糊状态=删失"而删失比例很高（cons 下 BF16 640/785，AWQ3 2266/2623 段被删失），其 KM 依赖"非信息删失"假设，不能当精确值。出口回到 G 的比例远大于直接 L→A（det 下 L→A 按定义为 0；hc 下 22–24%）。

### 3.3 正确答案之后到提交 [相关]
首次出现正确答案的轨迹：BF16 345 条、AWQ3 277 条。提交 = 生成 `</think>`。从首次正确答案到提交的延迟 KM：S(2000 token) BF16 0.35、AWQ3 0.79；S(8000) 0.09 vs 0.64；到预算耗尽仍未提交：2.3% vs 59.6%。已提交者最终答案错误：4.8% vs 8.9%。
正确中间答案之后出现过**不同的（错误）后续提案**：38% vs 57%（提案抽取含 labeler ANS，**精度未验证**）。

### 3.4 玩具模型 α/β/γ 的检验 [观察]
公式 E[T_A|G]=(1/γ)(1+α/β)（以"步"为单位）在 BF16 的 det 定义下与观察的受限均值接近（72 vs 74 步），在 AWQ3 过度预测（1157 vs 704）。假设被违反：(a) 入口风险随位置上升（非平稳）；(b) 出口风险随 L 段年龄急剧下降（AWQ3 det：前 8 步 0.095/步，之后 0.0078/步，约 12×；BF16 0.22 → 0.016），即有记忆/重尾；(c) hc 下存在 22–24% 直接 L→A。**放弃用该公式拟合；仅保留定性结论 α 上升、β 下降。**

## 4. B3 同前缀反事实续写（`prefix_bank.jsonl`、`counterfactual_results.csv`、`results/b3_submission_by_loop_status.csv`）

前缀库（规则在续写前固定，使用 hc 标签）：96 个前缀，来自 37 个题目（≥30 ✓）：G 32、L 32、CA（已明确提出正确答案）32；前缀来源 BF16 40 个（G16/L8/CA16）、AWQ3 56 个（G16/L24/CA16）。
同一 token 前缀，BF16 与 AWQ3 各从头重建 KV（两者都是 bf16 KV），3 个固定种子，上限 4096；25% 子集（hash 预定）用 8192 复核。两者差异按前缀配对、按题目聚类（B=2000）。主结果 [反事实]：

| 前缀类别 | 指标（4096 内） | BF16 | AWQ3 | AWQ3−BF16 [95% CI] |
|---|---|---|---|---|
| G（32 个前缀/28 题） | 进入逐字循环 | 0.010 | 0.219 | **+0.208 [0.125, 0.298]** |
| | 已提交（`</think>`） | 0.729 | 0.146 | −0.589 [−0.726, −0.446] |
| L（32/29） | 脱离循环（提交或末尾不在循环） | 0.854 | 0.521 | **−0.345 [−0.471, −0.218]** |
| | 再次/继续逐字循环 | 0.188 | 0.635 | +0.454 [0.293, 0.615] |
| CA（32/29） | 已提交 | 0.833 | 0.229 | **−0.580 [−0.730, −0.425]** |
| | 提交且答案正确 | 0.802 | 0.219 | −0.563 [−0.701, −0.425] |
| | 到提交的受限平均 token | 1772 | 3433 | +1593 [1181, 1964] |
| | 之后出现错误提案 | 0.010 | 0.010 | +0.006 [−0.017, 0.034] |

* 8192 子集（8–9 个前缀）方向一致（CA 提交 0.875 vs 0.292；G 进入循环 0.00 vs 0.78），样本太少只作方向复核。
* 未结束样本的删失：4096 内未提交比例 G：27%（BF16）/ 85%（AWQ3）；L：42% / 87%；CA：17% / 77%。
* **描述性（事后条件化，仅相关）**：CA 前缀的续写中，**没有逐字循环**的样本里提交率 BF16 0.85 vs AWQ3 0.32；有逐字循环的 AWQ3 续写提交率 0。即提交变差并非全部由逐字循环解释，但不能区分"非逐字的啰嗦/重复检查"与"直接的提交障碍"（B3 未用 labeler 对续写重新判 L，未完成）。
* 已有正确答案后"又放弃正确答案"在 4096 内很少发生（两者均约 1%）：主要损失是没提交，而不是改错。
* 混杂与局限：G 前缀（中位 854 token）明显短于 L 前缀（3435），CA 居中（1373），三类前缀长度没有匹配成功（G 候选被"尚无循环/尚无正确答案"约束，天然靠前）；前缀选择使用了 Qwen+检测器标签；只有 28–29 个题目簇；单一量化配置。

## 5. B4 分布分析（`results/distribution_results*.csv`、`results/b4_direction_*.csv`）

教师强制：两个模型读取同一 token 序列，逐位置流式保存 27 个标量（原始 logits 分布与实际采样分布（T=0.6→top-p=0.95）分别计算），不保存完整词表 logits；窗口级词表质量变化只保存各类别的累加向量。终止符核对：tokenizer 中 `</think>`=151649，EOS=`<｜end▁of▁sentence｜>`=151643；提交 = `</think>` + 答案段，EOS 在答案段之后；因此"提交"用 `</think>` 位置，不是 EOS。

### 5.1 哪些质量增加、哪些减少 [观察]
* 全体位置：量化模型熵略高（H_q−H_b 约 +0.07 nat）；窗口平均分布的净系统性位移（Σ|Δp̄|/2）约 2–3.5%，逐位置总变差（采样分布）均值约 8%。
* **marker 集合（49 个）质量**：AWQ3 比 BF16 在窗口内多约 +0.0008（绝对），与同轨迹位置匹配对照窗口的 +0.0007 几乎相同；在事件窗口内 BF16 的 marker 基线质量更高（pre-entry 0.022，in-loop 0.026 vs 对照 0.008），所以 **marker 概率高是"事件本身的特征"，不是"量化把 marker 概率抬高"**。
* **`</think>` / EOS 质量变化 ≈ 0**（pre-submit 窗口 AWQ3 −0.00004；其余为 0.0000），即在这些窗口里没有看到量化直接压低终止 token 概率。
* 最大的单 token 增益（in-loop，AWQ3 来源，原始分布）：`Wait`（行首，+0.0032，约为基线 0.0216 的 +15%）、`。\n\n`、`wait`、`perhaps`、`think` 等；损失集中在 `So`、`I`、`,`、`is`、`.\n\n`、`But`。即质量从"推进式"连接词向"重新检查式"词移动，但幅度小。
* 采样分布（T/top-p 之后）与原始分布给出同方向、略大的变化（如 in_loop marker +0.0012 vs raw +0.0011；BF16 的 nucleus 外质量 `sOut_b` ≈ 0.3–0.8%）。

### 5.2 是否预测后续转移 [相关]
step 级逻辑回归，按题目分组 5 折 CV 的 AUC（入口：860 个入口事件，100 题）：只用位置 0.74；加上 KL/熵 0.81；加 marker 0.79；加终止特征 0.79；全部 0.84。出口 L→G：位置 0.84 → 全部 0.92（但 BF16 内部仅 0.62→0.66）。G→A：位置 0.50 → 全部 0.68。高 KL 能提供**一些**预测信息，但幅度中等，且这些特征需要 BF16 模型才能得到，不是可部署信号。
窗口对照（pre-entry 窗口 128 token vs 位置匹配的 G 对照）：KL_bq 高 0.036（AWQ3 来源）/ 0.016（BF16 来源）；marker 与终止质量的量化差没有显著变化。

## 6. B5 位置受控 BF16 校正（`intervention_results.csv`、`results/intervention_cost.csv`、`figs/intervention_*.png`）

实现：在窗口内用 BF16 的 next-token 分布采样 W 个 token（等价于沿同一采样前缀把量化 logits 换成 BF16 logits；用 BF16 模型自己生成 W 个 token 实现），随后量化模型从"前缀 + 窗口"继续（仿真中重新 prefill，部署中只需 W 个 token 的追赶）。窗口位置全部是 **oracle 诊断**（利用了完整轨迹/标准答案），不能称为可部署方法：
E = 首次循环入口前 W token；I = 循环内部（第 4 个 L 步起）；A = 首次提出正确答案之后；V = 有效纠错害处检查（前缀止于"错误提案"之后，窗口紧随其后）。
C0 无干预；C1 全程 marker penalty（λ=1.0，第一阶段的实现）；CW BF16 窗口；C5 同轨迹内随机位置、熵匹配的等预算窗口（配各自的无干预对照 C0r）。每个题目每个族一个锚点（E/I/A 各 48，V 24），3 个种子，共 3438 条分支，续写上限 4096。

主结果（W=32，同前缀配对，95% CI 按题目聚类）[干预]：

| 族 / 指标 | BF16 窗口（oracle 位置） | BF16 窗口（随机位置） | 位置−随机 | 全程 marker penalty |
|---|---|---|---|---|
| E：进入逐字循环 | +0.049 [−0.028, 0.125] | −0.056 [−0.153, 0.042] | +0.104 [0.000, 0.208]（方向相反） | +0.042 [−0.021, 0.104] |
| I：脱离循环 | −0.090 [−0.174, −0.014] | −0.049 [−0.132, 0.035] | −0.042 [−0.160, 0.069] | +0.035 [−0.056, 0.125] |
| A：已提交 | +0.028 [−0.056, 0.111] | +0.042 [−0.021, 0.104] | −0.014 [−0.111, 0.076] | **+0.333 [0.243, 0.431]** |
| A：提交且正确 | +0.042 [−0.042, 0.118] | +0.042 [−0.021, 0.104] | 0.000 [−0.097, 0.090] | **+0.312 [0.222, 0.396]** |
| V：提交且正确（有效纠错害处检查） | −0.014 [−0.139, 0.111] | +0.014 [−0.083, 0.111] | −0.028 | **+0.194 [0.097, 0.292]** |

* 窗口敏感性（开发子集 22–28 个锚点，W=8/64）：同样没有任何位置优于随机的效应（例：A 提交，位置−随机 W=8：−0.015 [−0.197, 0.152]，W=64：−0.083 [−0.267, 0.117]）。
* **没有一种位置的 BF16 校正明显优于等预算随机窗口**；循环进入没有被阻断，循环退出没有增加（I 族甚至略降，但检验了很多比较，不作解读），答案提交没有恢复。
* 有效纠错害处检查 V：BF16 窗口对"提交且正确"没有可检出的损害；全程 penalty 也没有损害有效纠错（反而提高提交），**但**该检验样本只有 24 个锚点、4096 的视野，且 V 族锚点的"纠错"依赖 labeler 的 ANS 提取，只能说没看到损害，不能说没有损害。
* 注意：全程 marker penalty 提高了提交率和正确率，这是论文原方法（C1）在同前缀下的结果；它是全程干预，不属于位置受控方案。
* 一个与预期相反的观察：E 族（紧邻原轨迹循环入口前的前缀）重新采样后进入循环的概率只有 0.153，低于随机位置前缀的 0.285 —— 循环入口不是前缀的确定性函数（含回归均值效应），不存在一个可以"精确补救"的入口点。
* 成本（`results/intervention_cost.csv`，解析计数）：每次 CW 干预 BF16 前向 token（前缀 prefill + 窗口）约 1.6k–3.6k，相当于续写长度的 0.5–1.1 倍；BF16 权重额外约 3.5 GB（参数量×2 字节的估算，未实测；远大于 3-bit 权重本身）；BF16 KV 在窗口起点约 42–98 MB（28 KB/token）；仿真中量化模型重新 prefill（前缀+W），部署时只需 W 个 token 的追赶。单请求 wall time 在批处理中共享，不能当成速度结论。

## 7. 各假设的结论（区分证据等级）

| | 观察/相关 | 同前缀反事实 | 位置干预 |
|---|---|---|---|
| H1 入口损伤 | 四种定义下 G→L 风险 1.6–14× | G 前缀：进入循环 +21 个百分点 [12, 30] | 前缀紧邻入口也不会再入循环；入口前 BF16 窗口无阻断效果 |
| H2 出口损伤 | L 段持续更长，KM 与竞争风险一致 | L 前缀：脱离率 −35 个百分点 [−47, −22] | 循环内 BF16 窗口无增加退出（I 族 −9 个百分点，方向是变差；多重比较下不作解读） |
| H3 提交损伤 | 正确答案后 60% 未提交（BF16 2%） | CA 前缀：提交率 −58 个百分点 [−73, −43] | 答案后 BF16 窗口无恢复（+3 个百分点）；全程 penalty +33 个百分点 |

**判断：混合机制（入口、出口、提交均受损）。** 反例/不一致：
1. 短窗口 BF16 校正在所有位置、W=8/32/64 都无效，说明损伤不是"在入口/出口/提交那几十个 token 的单点 logit 错误"；更像持续性的倾向变化（**未验证**，见第 9 节）。
2. 量化后 marker 与 `</think>` 的概率质量与 BF16 相比几乎没变，所以"量化让 marker 概率虚高/终止概率被压低"这一直接解释，在这些窗口里没有得到支持；全程 penalty 有效很可能是因为把 marker 压到**低于**BF16 水平，这个机制本身未验证。
3. 提交损伤只有一部分由逐字循环解释（CA 前缀的非循环续写里 BF16 0.85 vs AWQ3 0.32），其余可能是非逐字的反复核对；B3 未用 labeler 复核。
4. 玩具模型的恒定速率假设被违反（非平稳、记忆、直接 L→A）。
5. labeler 对 BF16 的 L 高估，BF16/AWQ3 的 L 比例差异受测量误差影响；`det`/`cons` 定义下方向不变，但数值差异很大。

## 8. 与预注册的偏离与未完成项（逐条）

## 9. 未验证假设与下一项最有价值的实验

* [未验证] 损伤是持续性的"状态/倾向"变化：量化模型在 BF16 窗口之后迅速回到原有行为。
* [未验证] 全程 marker penalty 的有效性来自把"再核对"类 token 压到 BF16 以下，而不是恢复 BF16 的分布。
* **下一项最有价值的实验（代码已具备，只需改窗口长度）**：对 E/A 两族把 BF16 校正窗口扩到 W=256/1024/全程剩余，画"校正长度—收益"曲线，并加一组"只替换 KV（BF16 重新计算前缀 KV，权重仍为量化）"的对照；若收益只在很长窗口出现，则说明是持续性倾向变化而不是局部错误，且 BF16 双模型的成本不可接受；其次是人工标注 120 个窗口以定标 L 的精度。
